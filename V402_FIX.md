# V402 — Permanent sub-tabs + standalone Dashboard navigation

## Scope
Navigation presentation only. No Planning/Batch/Recipe/Schedule/Production business logic changed.

## Changes
- Dashboard is now its own first-level WORK CENTER tab.
- Removed Dashboard from the Vận hành sub-tab list.
- Vận hành now opens at All Open Jobs.
- All sub-tabs for Vận hành, Theo dõi, Master Data and Quản trị remain visible permanently instead of showing only the active module's sub-tabs.
- Applied the same navigation structure to migrated AppTabs pages and the native ERP Planning shell.
- Existing active-page highlighting is preserved for both the parent work center and the selected sub-tab.

## Result
The left rail always exposes the complete application navigation without requiring planners to enter a work center first to reveal its functions.
